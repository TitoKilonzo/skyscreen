    About this model

    The network was trained on a small public benchmark dataset of 569 patients. It reads 30 numbers measured from a digitised image of a cell sample and returns a probability. It was never tested on real clinical work.

    How to read a result

    • Probability is the network's confidence that the sample is malignant, from 0% to 100%.
    • Threshold turns that probability into a label. The tick on the gauge shows where it sits.
    • What influenced this result swaps each measurement for the training average and shows how far the result moves, longest bar first. It is an approximation, because the measurements are related.
    • Warnings appear when a value is far outside anything the model learned from, which usually means a unit mistake.

    Safety

    • Not for diagnosis, screening or any medical decision.
    • Everything runs on this computer. Nothing is sent anywhere, and no history is stored.
    • Keep the default address (127.0.0.1). Never expose this page to other computers: it has no password.
    • Do not type or upload real patient records.
